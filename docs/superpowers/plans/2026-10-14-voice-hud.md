# Voice HUD and System-wide Shortcut Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The voice-conversation shortcut works from any app, a floating HUD shows the conversation while Alethe is not focused (positionable, draggable), the shortcut is chosen by recording it, and narration speed (1x–2x) is selectable in the panel and the HUD.

**Architecture:** Rust `voice_hud.rs` owns the `voice-hud` window (an `NSPanel` on macOS via `tauri-nspanel`, a `focusable(false)` window elsewhere), its placement maths, the state/action relay between windows, and the global shortcut (`tauri-plugin-global-shortcut`). The main window keeps the phase 1 controller; it publishes the view state to the HUD, receives HUD actions, decides which surface shows from focus + phase, and registers the shortcut. The HUD window renders the same `VoiceConversationView`.

**Tech Stack:** Tauri 2.11 (`tauri-plugin-global-shortcut` 2.3, `tauri-nspanel` 2.1), Rust, React/TS, Zustand, Vitest.

**Spec:** [`docs/superpowers/specs/2026-10-14-voice-hud-design.md`](../specs/2026-10-14-voice-hud-design.md) — read it before any task. Phase 1 context: `docs/superpowers/specs/2026-10-14-voice-conversation-design.md`.

## Global Constraints

- **Never commit, push, tag or release** (CLAUDE.md §3.2). Working tree only; each task ends with a checkpoint.
- **Never start, stop or restart the app.**
- **Window label:** `voice-hud`. HUD fixed size **560 × 240** logical px. Preset margin **48 px**.
- **Positions:** `bottom-center` (default) · `bottom-left` · `bottom-right` · `top-center` · `top-left` · `top-right` · `custom`.
- **Custom position:** `{ monitor: string, x: number, y: number }`, `x`/`y` = top-left as fractions (0–1) of the monitor work area; clamped so the HUD stays fully visible.
- **HUD hides 4 s** after the turn goes idle (`HUD_IDLE_HIDE_MS = 4000`). Publish to the HUD at most every **100 ms**. Drag-end debounce **300 ms**.
- **Speed steps:** 1 · 1.25 · 1.5 · 2 (panel/HUD). Preferences speed options: 0.8 · 1 · 1.2 · 1.5 · 2.
- **Shortcut:** stored as an accelerator with `CmdOrCtrl` (e.g. `CmdOrCtrl+Shift+Space`); the Jev variant is `Alt+` + the same; a recorded shortcut may **not** contain Alt; needs a modifier unless it is F1–F24; supported keys A–Z, 0–9, F1–F24, Space; register **before** saving.
- **Label checks:** `voice_hud_show`, `voice_hud_hide`, `voice_hud_publish`, `voice_shortcut_set` only from `main`; `voice_hud_snapshot`, `voice_hud_action`, `voice_hud_moved` only from `voice-hud`.
- **The HUD never writes to a PTY and never decides permissions** — its actions go to the main-window controller.
- **New preferences** `voiceHudPosition`, `voiceHudCustomPosition` are device-specific: not in `cloudSync.ts`.
- **`tauri.conf.json`:** main window `backgroundThrottling: "disabled"`; `app.macOSPrivateApi: true` (required by `tauri-nspanel`, which enables Tauri's `macos-private-api` feature); the CSP is **not** touched (`src/securityPolicy.test.ts` must pass).
- **i18n** in `en.ts`, `pt-BR.ts`, `zh-CN.ts`; **CSS Modules + theme tokens** only; **English** code/comments/docs.
- CI runs lint, format:check, tests, build, cargo check/clippy/test: keep touched files clean. Known pre-existing failures: `npm run build` TS2550 ×2; 6 `format:check` files; parallel flakes in `git_control::wsl_git_argv_tests` and `remote::tests::listener_startup_*`.

1. **Holding the global shortcut, the HUD steals focus or the key-up is lost** → push-to-talk must release on the global `released` event even when another app is focused. Pinned in Task 6 (controller release on `voice://shortcut released` test).

```rust
//! The floating voice HUD: its window, where it goes on screen, and the relay between it and the
//! main window. This part holds the placement maths, kept pure so it can be tested.

use serde::Deserialize;

pub const HUD_WIDTH: f64 = 560.0;
pub const HUD_HEIGHT: f64 = 240.0;
pub const HUD_MARGIN: f64 = 48.0;

#[derive(Clone, Copy, Debug, PartialEq)]
pub struct Rect {
    pub x: f64,
    pub y: f64,
    pub width: f64,
    pub height: f64,
}

#[derive(Clone, Copy, Debug, PartialEq, Eq, Deserialize)]
#[serde(rename_all = "kebab-case")]
pub enum Preset {
    BottomCenter,
    BottomLeft,
    BottomRight,
    TopCenter,
    TopLeft,
    TopRight,
}

#[derive(Clone, Debug, PartialEq, Deserialize)]
pub struct CustomPosition {
    pub monitor: String,
    pub x: f64,
    pub y: f64,
}

#[derive(Clone, Debug, PartialEq, Deserialize)]
#[serde(tag = "kind", rename_all = "kebab-case")]
pub enum HudPlacement {
    Preset { preset: Preset },
    Custom { custom: CustomPosition },
}

#[derive(Clone, Debug)]
pub struct MonitorArea {
    pub name: String,
    pub work_area: Rect,
}

impl MonitorArea {
    #[cfg(test)]
    fn clone_area(&self) -> Self {
        self.clone()
    }
}

pub fn preset_origin(area: Rect, preset: Preset) -> (f64, f64) {
    let left = area.x + HUD_MARGIN;
    let center = area.x + (area.width - HUD_WIDTH) / 2.0;
    let right = area.x + area.width - HUD_WIDTH - HUD_MARGIN;
    let top = area.y + HUD_MARGIN;
    let bottom = area.y + area.height - HUD_HEIGHT - HUD_MARGIN;
    match preset {
        Preset::BottomCenter => (center, bottom),
        Preset::BottomLeft => (left, bottom),
        Preset::BottomRight => (right, bottom),
        Preset::TopCenter => (center, top),
        Preset::TopLeft => (left, top),
        Preset::TopRight => (right, top),
    }
}

/// Places a dragged HUD from its saved fractions, keeping all of it on screen.
pub fn custom_origin(area: Rect, x: f64, y: f64) -> (f64, f64) {
    let max_x = area.x + (area.width - HUD_WIDTH).max(0.0);
    let max_y = area.y + (area.height - HUD_HEIGHT).max(0.0);
    let ox = (area.x + x * area.width).clamp(area.x, max_x);
    let oy = (area.y + y * area.height).clamp(area.y, max_y);
    (ox, oy)
}

pub fn fractions_for(area: Rect, origin: (f64, f64)) -> (f64, f64) {
    let fx = if area.width > 0.0 { (origin.0 - area.x) / area.width } else { 0.0 };
    let fy = if area.height > 0.0 { (origin.1 - area.y) / area.height } else { 0.0 };
    (fx.clamp(0.0, 1.0), fy.clamp(0.0, 1.0))
}

pub fn origin_for(placement: &HudPlacement, monitors: &[MonitorArea], pointer: &MonitorArea) -> (f64, f64) {
    match placement {
        HudPlacement::Preset { preset } => preset_origin(pointer.work_area, *preset),
        HudPlacement::Custom { custom } => match monitors.iter().find(|m| m.name == custom.monitor) {
            Some(monitor) => custom_origin(monitor.work_area, custom.x, custom.y),
            // The saved monitor is not connected; the saved position stays for when it is.
            None => preset_origin(pointer.work_area, Preset::BottomCenter),
        },
    }
}

pub fn jev_accelerator(accelerator: &str) -> String {
    format!("Alt+{accelerator}")
}
```

```rust
fn monitor_areas(app: &AppHandle) -> Result<(Vec<MonitorArea>, MonitorArea), String> {
    let to_area = |m: &tauri::Monitor| {
        let scale = m.scale_factor();
        let wa = m.work_area();
        MonitorArea {
            name: m.name().cloned().unwrap_or_default(),
            work_area: Rect {
                x: wa.position.x as f64 / scale,
                y: wa.position.y as f64 / scale,
                width: wa.size.width as f64 / scale,
                height: wa.size.height as f64 / scale,
            },
        }
    };
    let monitors = app.available_monitors().map_err(|e| e.to_string())?;
    let areas: Vec<MonitorArea> = monitors.iter().map(to_area).collect();
    let pointer = app.cursor_position().ok()
        .and_then(|p| app.monitor_from_point(p.x, p.y).ok().flatten())
        .or_else(|| app.primary_monitor().ok().flatten())
        .ok_or_else(|| "no monitor".to_string())?;
    Ok((areas, to_area(&pointer)))
}

#[tauri::command]
pub async fn voice_hud_show(app: AppHandle, webview: tauri::WebviewWindow, placement: HudPlacement) -> Result<(), String> {
    require_window(webview.label(), "main")?;
    let Some(window) = app.get_webview_window(HUD_LABEL) else { return Err("the HUD is not available".into()) };
    let (monitors, pointer) = monitor_areas(&app)?;
    let (x, y) = origin_for(&placement, &monitors, &pointer);
    window.set_size(LogicalSize::new(HUD_WIDTH, HUD_HEIGHT)).map_err(|e| e.to_string())?;
    window.set_position(LogicalPosition::new(x, y)).map_err(|e| e.to_string())?;
    show_without_focus(&app, &window)
}
```

```ts
const MODIFIER_CODES = /^(Shift|Control|Alt|Meta|OS)(Left|Right)?$/

function keyName(code: string): string | null {
  if (code === 'Space') return 'Space'
  const letter = code.match(/^Key([A-Z])$/)
  if (letter) return letter[1]
  const digit = code.match(/^Digit([0-9])$/)
  if (digit) return digit[1]
  if (/^F([1-9]|1[0-9]|2[0-4])$/.test(code)) return code
  return null
}

/** Turns a key press in the shortcut recorder into an accelerator, or says why it cannot be one. */
export function acceleratorFromKeyEvent(
  event: KeyState & { key: string },
  mac: boolean,
): { accelerator: string } | { error: 'needs-modifier' | 'alt-reserved' | 'unsupported-key' } | { cancel: true } | { pending: true } {
  if (event.key === 'Escape' || event.code === 'Escape') return { cancel: true }
  if (MODIFIER_CODES.test(event.code)) return { pending: true }
  if (event.altKey) return { error: 'alt-reserved' }
  const key = keyName(event.code)
  if (!key) return { error: 'unsupported-key' }
  const parts: string[] = []
  if (mac) {
    if (event.metaKey) parts.push('CmdOrCtrl')
    if (event.ctrlKey) parts.push('Ctrl')
  } else if (event.ctrlKey || event.metaKey) {
    parts.push('CmdOrCtrl')
  }
  if (event.shiftKey) parts.push('Shift')
  if (parts.length === 0 && !/^F\d+$/.test(key)) return { error: 'needs-modifier' }
  return { accelerator: [...parts, key].join('+') }
}
```

```ts
/** Leading-edge throttle with a trailing run: the latest state always gets published. */
export function createThrottle(
  intervalMs: number,
  run: () => void,
): { schedule(): void; dispose(): void } {
  let last = -Infinity
  let timer: ReturnType<typeof setTimeout> | null = null
  let disposed = false
  const fire = () => {
    timer = null
    last = Date.now()
    if (!disposed) run()
  }
  return {
    schedule() {
      if (disposed || timer !== null) return
      const wait = last + intervalMs - Date.now()
      if (wait <= 0) fire()
      else timer = setTimeout(fire, wait)
    },
    dispose() {
      disposed = true
      if (timer !== null) clearTimeout(timer)
      timer = null
    },
  }
}
```
