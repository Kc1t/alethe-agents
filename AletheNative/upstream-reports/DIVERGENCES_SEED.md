## Method

Read AGENTS.md first; reviewed plan §5 ADRs, §6 interaction/shortcut guidance, §7 task outcomes
(including every explicit “Deviation”/“Deviations” note), and §8 parity matrix. Read the native
changelog and the root parity reports (TITLE_BAR, VOICE and ORCHESTRATION), and reviewed all Markdown
reports in upstream-reports, using targeted full sections and keyword/context searches for lengthy
reports. Compared selected current baseline files with `git show origin/main:<path>`: `src/lib/types.ts`,
`src/components/HomeView/SetupWalkthrough.tsx`, and `src-tauri/src/handoff.rs`; also inspected the
baseline file inventory. Most other baseline claims remain attributed to the plan/reports, often
written against older `2f3e5ed` or `f09c597` baselines, rather than asserted as a fresh full-web audit.
Confirmed selected native behaviors by reading the Swift paths in Verified cells; these are static
checks, not build or runtime validation. Excluded unported/Won't-port features without replacement,
implementation-only choices, resolved historical notes, and pixel-only parity gaps. Ambiguous and
superseded items remain above so each explicit plan deviation has a traceable disposition. No code,
registry, rule/checker, changelog, plan or other documentation was changed; no build, commit, push or
external ai-memory write was performed. This seed records the investigation and reviewer follow-ups.
